# Beryl OFOX16 prebuilts

Required version-matched binary inputs:

- stock vendor_boot.img — preserve the stock vendor ramdisk
- stock boot.img — source of the prebuilt kernel when no kernel source is available
- stock DTB/DTBO — use the exact stock DTB matching the kernel
- stock vendor DLKM modules — recovery allowlist in recovery-modules.list
- stock vendor SELinux policy — use the exact policy generated by the same build
- stock boot-control implementation — extract the exact vendor implementation from this build

The stock vendor_boot is Android boot-image header v4 and must be unpacked with Android boot-image tooling; v4 supports multiple vendor ramdisk fragments.

Do not mix kernel, DTB, modules, vendor ramdisk, boot-control or SELinux artifacts from another Beryl/HyperOS release.
